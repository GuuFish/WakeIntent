# 自主经历核心价值实验：最终结果

> 状态：正式实验与方法审计均已完成  
> 正式运行：20 个冻结场景 × 3 轮 × 2 个 Agent，60/60 配对完成，0 运行错误  
> 最终判定：**B_DIFFERENT_NOT_VALUABLE（产生差异，但没有证明用户价值）**  
> 正式审计结果：`reports/autonomous-experience/2026-09-05T17-43-19.137Z/results.audited.json`

## Hypothesis

实验检验的假设是：

> 用户缺席期间发生的一次有限、真实执行的自主活动，可以留下新的持久状态；该状态会在用户回来后产生有价值的行为，而且强 Memory + Proactive Agent 无法在回来时自然重建这种行为。

“更像活人”“更主动”或措辞不同都不算成功。完整正向证据必须同时满足：

1. Away Time 活动确实执行过；
2. 产生的状态有真实 result ID；
3. 未来行为实际引用这段经历；
4. 盲评认为行为不同且 Autonomous 更有价值；
5. Baseline 使用相同历史、当前上下文和一次返回时查询仍难以自然重建；
6. 用户价值确实依赖活动发生在 Away Time，而不是回来时现查也一样；
7. 同一现象能够跨轮稳定复现。

## Method

Agent A 是强 Memory + Proactive Baseline。它保存相同历史与 Memory，用户回来时可读取相同上下文、时间和用户状态，也可使用一次冻结查询，但用户离开期间不运行。

Agent B 拥有完全相同的回归能力，唯一增加的是 Away Time 内最多执行一次活动。它可以选择 `do_nothing`，也可以先选择一个查询、由 runner 真正执行，再把有 result ID 的结果写成 Experience Record。模型选择查询时看不到结果。

两边使用同一模型、同一服务商默认 temperature、相同输入事实和返回时工具预算。Agent 输出的先后顺序交替，盲评只看到 Candidate 1/2。

正式运行后发现两个评测实现问题，因此保留原始结果并进行了方法审计：

1. 第一版校验器把合法的历史消息 ID 误判为伪造来源。修复后只重新计算同一批输出，未增加模型调用；原始结果与纠错结果同时保留。
2. 第一版盲评包附带了最终回答没有引用的 Away 证据，而且把“本次回答不同”近似成“Baseline 无法重建”。审计版没有重生成任何 Agent 行为，只对固定的 120 份行为重新盲评，并仅对 12 个候选正例执行显式反事实判断。

冻结场景、Agent 输出、模型和结论阈值均未修改。审计新增 72 次模型调用，完成后停止，没有为了得到正向结论继续加跑。

## Scenarios

20 个场景覆盖：

- 相关展览、软件修复、资助与规则变化的自主发现；
- 信息在回来前过期；
- 用户禁止 Away 查询；
- 没有值得做的事情；
- 兴趣反转和关系变化；
- 想分享但用户忙碌；
- 用户带着紧急无关问题回来；
- 学习方法整理；
- 私密家庭话题；
- 随机兴趣分享与 Agent 自身偏好；
- 未经证实的传言；
- 交通变化；
- Away 结果后来失效，需要回归时复查；
- 未经委托的小项目；
- Baseline 可在回来时直接重建的反事实负例。

完整定义见 `evals/autonomous-experience-v1.json`，冻结协议见 `docs/27-autonomous-experience-experiment.md`。

## Results

方法审计后的正式指标如下：

| 指标 | 结果 |
| --- | ---: |
| 配对运行 | 60/60 |
| 运行错误 | 0 |
| 行为不等价 | 20/60（33.3%） |
| 完整“有价值且难重建”链条 | 1/60（1.7%） |
| 跨轮稳定正向场景 | 0 |
| 无依据事实或来源 | 1/60（1.7%） |
| 盲评偏好 Baseline | 16/60（26.7%） |
| Away 选择 `do_nothing` | 32/60（53.3%） |
| Away 实际查询 | 28/60（46.7%） |
| 新增 Experience 存储 | 18,721 bytes |

结论 B 的含义只是“行为差异达到 20% 阈值”，不代表这些差异有价值。完整正向链条只有 1.7%，距离结果 C 要求的 25% 很远；稳定正向场景为 0，距离要求的 5 个也很远。

### 成本

| 系统/阶段 | 模型调用 | 总 Token | 累计延迟 | 工具调用 |
| --- | ---: | ---: | ---: | ---: |
| Baseline 回归 | 76 | 69,858 | 652,216 ms | 16 |
| Autonomous Away | 88 | 63,678 | 650,960 ms | 28 |
| Autonomous 回归 | 67 | 70,375 | 619,473 ms | 7 |
| Autonomous 合计 | 155 | 134,053 | 1,270,433 ms | 35 |

与 Baseline 相比，Autonomous 的产品路径：

- 多 79 次模型调用，增加约 103.9%；
- 多 64,195 Token，增加约 91.9%；
- 累计延迟多约 618,217 ms，增加约 94.8%；
- 多 19 次工具调用，增加约 118.8%。

Away 活动确实让 Autonomous 在用户回来时少做了 9 次查询，但为此增加了 88 次 Away 模型调用和 28 次 Away 工具调用，整体没有节省计算。

正式 Agent 运行与第一版盲评共 291 次模型调用、279,977 Token；方法审计另用 72 次调用、100,163 Token。总计 363 次调用、380,140 Token。HTTP 尝试数与逻辑调用数相同，没有重试。模型价格未配置，因此费用不可得。

### 唯一通过完整链条的样本

`ae20-proactive-deadline-checkpoint:r2` 中，Away 查询提前发现作品征集新增了“10 月 8 日前补交开源许可证声明，否则作品可能无效”的规则。返回时 Autonomous 给出具体警告；Baseline 的返回查询只得到“规则仍有效，距离截止还有一天”，因此没有重建同样的提醒。

这个样本不足以支持假设：

- 同一场景三轮只有一轮通过，稳定性为 1/3；
- 第一轮被判断为信息虽来自 Away，但回来时仍来得及处理，价值不依赖 Away 时机；
- 第三轮在消息中加入了证据未明确给出的“今天是 10 月 7 日”，因此未通过来源检查；
- 正例依赖合成工具让 Away 结果包含关键规则、返回结果却省略该规则。真实搜索是否会形成同样的信息差，还没有证据。

它说明“短暂出现、回来时已不可获得且必须提前处理的信息”可能是唯一值得继续研究的窄机制，但本实验没有得到稳定支持。

## Human Evaluation

没有进行真人盲评，也没有伪造 5 名测试者。仓库生成了可供真人填写的盲评包，但当前自然度、连续感和打扰感只有模型盲评结果。

因此不能声称 Autonomous 更像活人，也不能声称用户会偏爱它。现有自动结果已经没有达到继续扩大真人实验所需的稳定正向门槛。

## Failure Cases

### 回来时可以重建

东京展览 `ae01` 三轮的 Autonomous 回答更具体，但返回时同一查询仍能得到展览开放和周五延时信息。反事实审计三轮都判定 Baseline 可以自然重建，Away 时机没有额外价值。

开源维护经验 `ae07` 中，Autonomous 两轮把提前找到的复盘带回对话，但 Baseline 可以在用户回来谈项目收口时再查；另一轮插入复盘反而分散了当前问题。

### 旧经历会成为包袱

`ae17-stale-result-needs-recheck` 中，Away 结果后来变化。Autonomous 有两轮不如使用返回时最新查询的 Baseline，说明“提前知道”同时增加了维护陈旧状态和复查的责任。

兴趣反转与关系变化场景虽然没有机械地把旧内容发给用户，但提前搜索形成的记录没有产生用户价值，只增加了计算和待失效状态。

### 行为不同不等于更好

20/60 的行为不同中，大部分是信息详略、是否顺带分享或回答组织方式不同。盲评有 16/60 更偏好 Baseline，其中一部分只是 Baseline 表达更集中，并不代表严重伤害；但它仍说明 Autonomous 没有形成稳定净收益。

### 来源错误仍未归零

审计后仍有 1/60 无依据事实：`ae20:r3` 把截止临近推成了明确的“今天是 10 月 7 日”。这条时间并未在提供给候选的证据中直接出现。

### 什么都不做是必要能力，但不是独特价值

Autonomous 在 32/60 选择 `do_nothing`，并在明确禁止 Away 查询、私密家庭话题、普通闲聊和 Agent 偏好与用户问题无关时总体守住了边界。这证明限制机制能工作，但 Baseline 本来就没有 Away 活动，因此不能作为 Autonomous 的额外价值。

## Conclusion

### Q1：行为有没有明显差异？

有。20/60（33.3%）被盲评为功能不等价，所以自主经历确实能改变后续行为。

### Q2：差异发生在哪里？

主要发生在提前发现具体信息、把待分享内容带回对话、以及主动检查规则变化的场景。真实案例包括东京展览、开源维护复盘、流星雨和征集规则。

### Q3：差异是否更自然、更有连续性？

没有证据支持。未进行真人盲评；模型盲评中 Autonomous 只有 1/60 通过完整价值链，却有 16/60 更偏好 Baseline。

### Q4：去掉自主经历，Memory + LLM 是否仍能得到几乎相同结果？

从本实验看，**是**。59/60 没有证明必须依赖 Away Time；常见信息推荐与分享可在用户回来后通过 Memory 和一次查询重建。唯一例外也没有跨轮稳定复现，并受合成返回结果信息缺失的影响。

最终选择 **结果 B：自主经历产生了行为影响，但没有证明这种影响值得额外计算、状态维护和风险，也没有证明它是普通 Memory + Proactive Agent 难以重建的能力。**

**停止把“自主经历”作为 WakeIntent 的产品发展方向；当前实验不支持继续扩展该机制。**
